# 《2026 決策智慧》DIVE

dentsu Taiwan《2026 決策智慧 Decision Intelligence》的 3D 互動版本：從雨夜屋頂往下潛，經過運河、水下、深網，22 篇觀點在不同深度等你。按住空白鍵開啟魂視。

網站：[`/shell/`](shell/)（根目錄會自動轉過去）

還有「螺旋書塔」：[`/tower/`](tower/)——196 頁從書裡飛出，繞成一座可以漫步的螺旋書塔；每篇有重點摘要、原文翻閱與主題線索。

純靜態網站（three.js r170，從 jsDelivr 載入），不需要建置。本機預覽：雙擊 `start-shell.bat`（DIVE）或 `start.bat`（螺旋書塔），或在這個資料夾執行 `python -m http.server 8765`，再打開 http://localhost:8765/shell/ 或 http://localhost:8765/tower/。
